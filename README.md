# Vocabulary Master

English Vocabulary Learning App — Cloud version with Supabase sync.

Open [index.html](index.html) or visit the GitHub Pages URL to use the app.

## Features
- 📖 All Vocabulary — add, generate, search, filter
- 🎯 Studying List — drag & drop, sync across devices
- 🃏 Flashcards — random card flip practice
- 🔊 Text-to-Speech pronunciation
- ☁️ Supabase realtime sync — data persists across all devices
